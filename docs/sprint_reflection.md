# Group 1 — Sprint 1 Reflection
**CPSC-620: Agile Software Development**  
**Project: NYC Airbnb Analytics Tool**

### What Went Well

Our team successfully applied Agile development practices to build a modular Python analytics tool for the NYC Airbnb dataset. We divided tasks among four members and used GitHub Issues, feature branches, pull requests, and GitHub Projects to coordinate our sprint.

We implemented data loading, inspection, cleaning, and summaries for listings, pricing, and availability. Our integrated pipeline processed 42,336 original records, producing 42,000 cleaned records. GitHub Actions also confirmed that 77 automated tests passed on our integration branch.

Peer reviews strengthened our implementation. Team members provided constructive feedback, identified missing validation requirements, and improved the reliability of our code.

### Challenges Encountered

One major challenge was coordinating multiple feature branches while different team members developed dependent modules. We encountered merge conflicts and had to synchronize branches carefully.

Handling missing and invalid dataset values also required additional testing. Another challenge was managing task dependencies, particularly when integration work depended on functions being implemented and reviewed by other team members.

### Lessons Learned

We learned that effective Agile development requires continuous communication, clearly defined acceptance criteria, and regular integration. Automated testing was particularly valuable because it helped identify problems before merging code.

GitHub Issues and pull requests improved transparency and accountability by documenting contributions, review feedback, and development progress.

### Improvements for Future Sprints

In future sprints, we would establish earlier integration checkpoints, communicate dependencies sooner, and allocate more time for final testing and documentation. We would also encourage smaller, more frequent pull requests to reduce integration difficulties.

Overall, this sprint strengthened our understanding of collaborative software development, Agile teamwork, version control, and continuous testing.
